# Enterprise Retail AI Analytics

> **End-to-end Data Analyst portfolio project** covering Excel, SQL, Python/Pandas, Power BI, Tableau, AI/risk analytics, business storytelling, documentation, and QA.

## Business problem
A retail business needs one analytical view of sales, profitability, customer behavior, regional/category performance, marketing/operations signals, returns, cancellations, and risk. This project turns order-level data into decision-ready analysis and dashboards.

## Stack
**Excel · SQL · Python · Pandas · Power BI · DAX · Tableau · AI/Risk Analytics · Git/GitHub**

## Start here
1. Open `00_START_HERE/README.md`.
2. Review `07_DATA/retail_orders_sample.csv`.
3. Open `05_PYTHON_ANALYTICS/Enterprise_Retail_Analytics.ipynb`.
4. Run SQL from `06_SQL/enterprise_retail_business_analysis.sql`.
5. Open the Excel workbook.
6. Open the Power BI `.pbix`.
7. Review the Tableau visuals.
8. Read `08_REPORTS/Business_Insights.md`.

## Important artifact note
The Power BI file is included as a direct `.pbix`. Tableau is included as one canonical packaged `.twbx` workbook. The packaged workbook contains the project Tableau workbook and its packaged Hyper data so it can be opened directly in Tableau Desktop.
