# 3. Data Dictionary

| Field | Meaning |
|---|---|
| order_id | Unique order identifier |
| order_date | Order creation date |
| region | Geographic sales region |
| category | Product category |
| product_name | Product/product family |
| revenue | Sales/revenue amount |
| profit | Profit amount |
| order_status | Completed/delivered, returned or cancelled status |
| customer_id | Customer identifier |
| customer_segment | Customer grouping used in Customer 360 |

These are the intended analytical concepts; exact source columns depend on the underlying dataset.
