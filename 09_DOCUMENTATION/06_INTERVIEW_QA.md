# Interview Q&A

## 1. What business problem does this solve?
The project helps a retail business understand revenue, profitability, customer activity, regional/category performance, returns, cancellations, and risk so managers can prioritize actions.

## 2. Why multiple tools?
SQL answers repeatable business questions, Python performs EDA and validation, Excel supports accessible reporting, Power BI supports executive BI, Tableau provides an additional visual analytics layer, and the AI/risk layer turns metrics into decision-support signals.

## 3. Is the data from a real company?
No. The repository uses a synthetic portfolio dataset. It is intentionally disclosed as such.

## 4. What would you do with production data?
Add source-system ingestion, data-quality monitoring, role-based access, incremental refresh, a governed semantic model, model validation, and production deployment controls.

## 5. What are the key KPIs?
Orders, customers, revenue, profit, profit margin, average order value, return rate, cancellation rate, and discount rate.

## 6. How was AI used?
AI is used as a decision-support/risk framework around the analytics outputs. The project does not claim a production ML model or predictive accuracy unless separately trained and validated.
