# GitHub Upload Guide

1. Extract the ZIP.
2. Open the `Enterprise_Retail_AI_Analytics_GITHUB_FINAL` folder.
3. Create a new GitHub repository.
4. Upload the **contents of this folder**, not the outer ZIP.
5. Keep the folder structure unchanged.
6. Open `README.md` first.
7. Open the PBIX from `03_POWER_BI` in Power BI Desktop.
9. Open the Excel workbook from `02_EXCEL_DASHBOARD`.
10. Review `PHOTOS_PNG` for portfolio visuals and `04_TABLEAU` for the packaged Tableau workbook.

## Recommended GitHub presentation
Pin the repository, add a concise repository description, and put the strongest Power BI/Excel/Tableau image near the top of the README.
