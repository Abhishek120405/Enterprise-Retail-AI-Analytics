# Reproducibility

The project is designed so the analytical layer can be reproduced from the included sample data.

- CSV: `07_DATA/retail_orders_sample.csv`
- SQLite DB: `07_DATA/enterprise_retail_sample.db`
- Schema: `07_DATA/schema.sql`
- SQL: `06_SQL/enterprise_retail_business_analysis.sql`
- Python notebook: `05_PYTHON_ANALYTICS/Enterprise_Retail_Analytics.ipynb`
- Dataset validator: `11_TESTS/validate_dataset.py`
- Excel: `02_EXCEL_DASHBOARD/Enterprise_Retail_Excel_Dashboard_FINAL.xlsx`
- Power BI: `03_POWER_BI/Enterprise_Retail_AI_Analytics_final.pbix`

The dataset is synthetic and included so reviewers can reproduce the SQL/Python/Excel workflow without access to confidential company systems.
